# Dialog

Pergunta que interrompe: confirmações destrutivas e escolhas que não podem esperar.

- Fundo `overlay`, cartão `surface` com `radius-xl` e `shadow-lg`, entrando com `lm-rise`.
- Título é a pergunta; o texto diz a consequência; o botão repete o verbo ("Excluir link", não "OK").
- No celular vira folha que sobe de baixo, com a mesma estrutura.
- Foco preso dentro do diálogo; Esc e "Cancelar" fecham.
