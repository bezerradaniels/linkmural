# Icons

Ícones de traço, desenhados no mesmo espírito das barras do símbolo.

- Grade de 24px, traço 1,8px, pontas e cantos arredondados, sem preenchimento (`lm-ico`).
- Tamanhos: 16px em chips e textos pequenos, 20px no padrão, 24px em destaques.
- Cor = cor do texto ao lado (`currentColor`). Lime só quando o ícone está sobre `ink`.
- Redes sociais seguem o mesmo traço, sem os logotipos coloridos oficiais.
- Os 8 ícones de uso mais comum também estão como arquivos no grupo Icons.
