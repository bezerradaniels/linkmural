# Avatar

Logo ou iniciais do negócio e da pessoa.

- Sem imagem: iniciais em Unbounded sobre lime (pessoa) ou ink com cantos arredondados (`--square`, para negócios).
- Anel lime (`--ring`) só para destacar quem está em evidência, como o perfil na página pública.
- Tamanhos: 32, 48, 56, 64px. Com foto, `object-fit: cover`.
