# TextLink

Link dentro de texto: sublinhado lime de 2px que, no hover, sobe e vira um marca-texto atrás da palavra.

- Use dentro de frases. Para ações isoladas, use Button (ghost ou outline).
- Cor do texto sempre `ink`; o lime fica só no sublinhado e no fundo do hover.
- Transição `duration-base` com `ease-out`.
