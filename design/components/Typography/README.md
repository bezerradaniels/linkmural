# Typography

Como as duas fontes trabalham juntas na prática.

- **Unbounded** (`display`): títulos e números grandes, de 26px para cima, peso 600, espaçamento −3%. Nunca em parágrafos ou botões.
- **Inter** (`sans`): tudo o mais. Corpo 15px, apoio 13px, rótulos 11,5px.
- Uma página usa no máximo 3 tamanhos de texto por bloco.
