# DatePicker

Escolha de um período para métricas, relatórios e faturas.

- Semana começa no domingo (D S T Q Q S S), como nos calendários do Brasil.
- Período: início e fim em `ink`, dias do meio em `lime-soft`; hoje com contorno `ink`.
- Datas futuras desativadas quando não fazem sentido (métricas).
- Atalhos embaixo (Hoje, 7 dias, 30 dias, Este mês) resolvem a maioria dos casos com um toque.
- No celular, abre dentro de um Sheet.
