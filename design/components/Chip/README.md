# Chip

Opção que liga e desliga, em grupo: filtros e a escolha de links no onboarding.

- Desligado: contorno `line-strong`. Ligado (`aria-pressed="true"`): fundo `ink`, texto `paper`.
- Altura 36px; ícone de 16px opcional à esquerda.
- Para uma escolha única entre 2 a 4 opções, prefira o Segmented.
