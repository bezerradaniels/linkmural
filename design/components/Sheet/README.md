# Sheet

Folha que sobe de baixo no celular: o Dialog e o Select do celular.

- Sobe com `lm-sheet-up` em `duration-slow`; cantos de 24px só em cima; a "alça" indica que dá para arrastar para fechar.
- Título em Unbounded à esquerda, botão fechar à direita, ação principal no fim, larga, ao alcance do polegar.
- Altura só a necessária; acima de 90% da tela, vira página.
- Fecha arrastando para baixo, tocando fora ou no X.
