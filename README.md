# LinkMural

Aplicação web construída com Next.js, configurada para deploy na Hostinger via GitHub.

- **Domínio:** https://linkmural.com
- **Repositório:** https://github.com/bezerradaniels/linkmural

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm start
```
